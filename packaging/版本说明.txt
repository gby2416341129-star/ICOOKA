酷咔管理系统 1.3.0
==================

本版本仅重构 UI 与交互，不增加或删除业务功能，不改变现有 SQLite 数据结构。

主要更新
1. 全新 Windows 11 风格自定义窗口：统一 Logo、页面标题、版本号以及最小化/最大化/关闭按钮。
2. 登录、初始化、账户、表单和财务编辑窗口统一视觉框架。
3. 中文使用 Microsoft YaHei UI，英文数字使用 Segoe UI / Segoe UI Variable；启用 Per-Monitor V2 DPI、ClearType、像素对齐。
4. 重写 Primary、Secondary、Danger、Icon Button 模板，消除圆角白边，并补齐 Hover、Pressed、Focus、Disabled 状态。
5. 统一 TextBox、PasswordBox、ComboBox、DatePicker、CheckBox、RadioButton 样式。
6. 修复 ComboBox 显示“FormChoice { Text=..., Value=... }”的问题。
7. 左侧导航改为 Fluent 分组导航，并在标题栏同步显示当前页面。
8. DataGrid 统一 44px 表头、48px 行高、16px 文本基线、悬停、选中、交替行和空数据状态；解决表头与正文错位。
9. 修复页面与表格滚动冲突；Shift + 鼠标滚轮可横向滚动宽表格。
10. 仪表卡和财务筛选支持较窄窗口自动换行，兼容 1366×768 到 4K。
11. 全局统一 24px 卡片内边距、页面标题、说明文字、工具栏和表单纵向节奏，修复各模块普遍存在的拥挤与错位。
12. 日期选择器改为 Windows 11 风格圆角日历，包含现代导航、圆形日期状态、淡阴影与月份/年份视图。
13. 财务中心切换区、同步状态和操作按钮重新分层，避免小字与按钮挤在同一行。
14. 修复现代日历模板因错误 Trigger 属性导致程序启动失败的问题。

数据位置
首次运行会自动在以下位置创建正式数据库：
%LOCALAPPDATA%\KukaManager\kuka.sqlite3

升级说明
可直接运行本版本。已有 1.2.0 数据会继续使用，并在启动和退出时自动备份。
